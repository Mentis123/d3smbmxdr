# Coastwater · the pilot that became policy

## Run the workshop

Open `/decision-room/coastwater`. Rehearse the entire presentation without a key using **Rehearse the full presentation**. For live table responses, choose **Facilitate**, enter the existing facilitator key, select 3–4 tables and create a new room. The presentation opens directly.

Every table uses one device and joins via the QR code or `/decision-room/join`. Each table selects A–D, records its reasoning and confidence, then locks its call. Include any minority view in the rationale.

The welcome screen shows the room's joining instructions: open **bit.ly/4evinZE**, select **Coastwater**, choose **Join a table**, enter the displayed room code and choose a table. Coastwater home opens on the join form. The QR code offers a direct route into the room.

In **Full room controls**, set **Session date**, **Start time** and **Length (minutes)**, then **Save session plan**. Date and time use **Australia/Sydney**, including daylight saving. Settings belong to the room and remain after a reload or device change. The adjusted agenda preserves the scenario's relative timing and its scheduled finish. A late actual start compresses the remaining agenda. Presenter and table voting countdowns use the same timing. You can also edit the plan from **Workshop controls** in the presenter. Timing remains advisory and never closes a vote automatically.

The presenter is the facilitator control surface. Keep it on the workshop display. **Next** or the right arrow proceeds through two opening screens, five screens for each of six modules, then the closing read-back. Back reviews an earlier screen without undoing votes.

1. Situation: explain what changed.
2. Decision: opens voting and starts the four-minute discussion clock.
3. Discussion: closes voting and shows the split of locked calls. Hear different views.
4. New information: publishes the reveal and table results. Ask whether the new evidence changes the judgement.
5. Boundary: record permission, conditions, owner and escalation trigger.

After the sixth boundary, Next ends voting and opens the closing read-back. The room report and vote export remain available.

## Controls and recovery

- Full screen hides browser chrome where supported. Notes are optional and explicitly visible on the display when opened.
- The controls menu offers vote CSV export, boundary text export, the full room controls and the round report.
- The presentation position and captured boundaries are stored in this browser, under a revisioned key per room. Download the boundaries before changing devices. They are not stored on the server.
- Votes, confidence and rationales use the existing durable workshop room system. A new browser can recover the live round with the facilitator key and the presenter URL containing the room ID. It cannot recover boundaries captured only in the previous browser.
- A connection failure stops live advancement and shows an error. Retry when connected. Rehearsal works for spoken or paper discussion without API calls.
- To revise a locked vote before publication, open full room controls and reopen that table. To reopen all voting before the reveal, use the existing unclose action there.
- No answer key, preferred letter, measured safety outcome, scoring or ranking exists for Coastwater.

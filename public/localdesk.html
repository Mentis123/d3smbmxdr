This opens a new tab on your own computer. The app needs to be installed and running there.

First visit, or the app is not running?
  1. On the PC where Local Desk was set up, open its app folder and double-click Start Local Desk.cmd (or the Local Desk shortcut).
  2. The launcher starts the local services and opens the workspace. You can also use the button above once it is running.
  3. If the local tab says it cannot connect, run the launcher again. On another computer, Local Desk must be installed on that computer first.
